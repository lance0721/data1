# 超星刷课助手-泛雅（Chrome 插件）
如果遇到跳转失败的情况，有可能是视频本身问题，手动刷新或者手动跳过即可


## 安装 / 更新步骤

1. 打开 Chrome，地址栏输入 `chrome://extensions/` 回车
2. 打开右上角的 **「开发者模式」** 开关
3. 页面右上角出现 **「📚 超星刷课助手 v2」** 悬浮面板，点 **「开始」**


| 功能 | 实现方式 |
|---|---|
| 自动静音播放 | 视频 `muted = true` 后调用 `play()`，失败时自动点击播放器播放按钮兜底 |
| 顺序播放本页视频 | token 注册表逐个调度，同时只有一个视频在播，`ended` 后播下一个 |
| 跳过已完成任务点 | 任务点图标 `.ans-job-icon` 带 finish/green 类（变绿）即跳过；视频时长已走满也跳过 |
| 不拖进度条、不跳过 | 从头到尾正常播放，进度由超星播放器正常上报 |
| 自动进入下一章 | 三级策略：① 官方「下一节」按钮 `#prevNextFocusNext`；② 文字匹配「下一章/下一节」；③ 目录树兜底（`#coursetree` 定位 `.posCatalog_active` 当前小节 → 点击下一小节/下一章第一节）；8 秒冷却后循环 |
| 卡死保护 | 视频暂停且进度 15 秒无变化（播放器不触发 ended）→ 判定完成，继续下一节 |
| 自动点掉弹窗 | 自动确认「确定/确认/继续」类弹窗 |
| 防中断 | 意外暂停 1 秒内自动恢复 |
| 状态记忆 | 刷新/跳章重载后自动继续 |
| 倍速可调 | 1x / 1.25x / 1.5x / 2x，默认 1x 最稳 |
